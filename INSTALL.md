# 📥 INSTALACIÓN - DECIDE v2.0\n\n## Requisitos del Sistema\n\n- **Python**: 3.6 o superior\n- **Espacio en disco**: ~5 MB\n- **RAM**: 256 MB mínimo\n- **Sistema Operativo**: Windows, macOS o Linux\n\n## Verificar Python\n\n### Windows\n```bash\npython --version\n```\n\n### macOS y Linux\n```bash\npython3 --version\n```\n\nSi no tienes Python, descargalo desde: https://www.python.org/downloads/\n\n## Instalación Paso a Paso\n\n### 1. Descargar el Proyecto\n\n```bash\n# Opción A: Clonar desde git\ngit clone [URL-DEL-REPOSITORIO]\ncd AppCarlos\n\n# Opción B: Descargar ZIP y extraer\n# Extrae el archivo y abre la carpeta AppCarlos\n```\n\n### 2. Verificar Estructura\n\nAseúrate de que la carpeta contenga:\n```\nAppCarlos/\n├── main.py\n├── interfaz_mejorada.py\n├── basedatos.py\n├── gamificacion.py\n├── evaluador.py\n├── situaciones.py\n├── competencias.py\n├── recomendaciones.py\n├── resultados.py\n├── config.py\n├── requirements.txt\n├── README.md\n└── GUIA_USO.md\n```\n\n### 3. Instalación de Dependencias (Opcional)\n\n**DECIDE funciona sin dependencias externas**, pero si quieres instalar las listadas:\n\n```bash\n# Windows\npip install -r requirements.txt\n\n# macOS y Linux\npip3 install -r requirements.txt\n```\n\n## Ejecutar la Aplicación\n\n### Windows\n\n**Opción 1: Terminal de Comandos**\n```bash\ncd C:\\ruta\\a\\AppCarlos\npython main.py\n```\n\n**Opción 2: Crear un ejecutable (archivo .bat)**\n1. Abre el Bloc de Notas\n2. Escribe:\n```batch\n@echo off\ncd /d %~dp0\npython main.py\npause\n```\n3. Guarda como `iniciar_decide.bat` en la carpeta AppCarlos\n4. Haz doble clic en el archivo para ejecutar\n\n**Opción 3: PowerShell**\n```powershell\nSet-Location C:\\ruta\\a\\AppCarlos\npython main.py\n```\n\n### macOS y Linux\n\n**Opción 1: Terminal**\n```bash\ncd ~/ruta/a/AppCarlos\npython3 main.py\n```\n\n**Opción 2: Crear un script ejecutable**\n1. Abre Terminal\n2. Navega a la carpeta:\n```bash\ncd ~/ruta/a/AppCarlos\n```\n3. Crea un archivo `iniciar_decide.sh`:\n```bash\necho '#!/bin/bash' > iniciar_decide.sh\necho 'python3 main.py' >> iniciar_decide.sh\nchmod +x iniciar_decide.sh\n```\n4. Ejecuta:\n```bash\n./iniciar_decide.sh\n```\n\n## Solución de Problemas\n\n### Error: \"python: command not found\"\n\n**Solución:**\n- Instala Python desde https://www.python.org\n- En Windows, asegúrate de marcar \"Add Python to PATH\" durante la instalación\n- En macOS, usa: `python3` en lugar de `python`\n\n### Error: \"No module named 'tkinter'\"\n\n**Solución Windows:**\n```bash\npython -m pip install tk\n```\n\n**Solución macOS:**\n```bash\nbrew install python-tk@3.9  # o la versión de Python que tengas\n```\n\n**Solución Linux (Ubuntu/Debian):**\n```bash\nsudo apt-get install python3-tk\n```\n\n### Error: \"Permission denied\" (Linux/macOS)\n\n```bash\nchmod +x main.py\npython3 main.py\n```\n\n### La aplicación abre pero se cierra inmediatamente\n\n- Ejecuta desde terminal para ver el error\n- Verifica que todos los archivos .py estén en la misma carpeta\n- Comprueba que no hay caracteres especiales en la ruta de la carpeta\n\n### Base de datos corrupta\n\nSi la base de datos se daña:\n```bash\n# Elimina el archivo de BD (perderás datos)\nrm decide_datos.db  # Linux/macOS\ndel decide_datos.db # Windows (CMD)\n\n# Ejecuta la aplicación nuevamente, se creará una BD nueva\npython main.py\n```\n\n## Desinstalación\n\n**Windows/macOS/Linux:**\n```bash\n# Simplemente elimina la carpeta AppCarlos\nrm -rf AppCarlos  # Linux/macOS\nrmdir /s AppCarlos  # Windows (CMD)\n```\n\n**Nota:** Los datos se almacenan en `decide_datos.db` dentro de la carpeta. Si deseas guardarlos, haz una copia de ese archivo antes de eliminar la carpeta.\n\n## Actualizar a una Versión Más Nueva\n\n1. Realiza una copia de seguridad de tu `decide_datos.db`\n2. Descarga la versión nueva\n3. Reemplaza los archivos .py\n4. Coloca tu `decide_datos.db` anterior en la nueva carpeta\n5. Ejecuta la aplicación\n\n## Recursos Adicionales\n\n- **Documentación**: Ver `README.md`\n- **Guía de Uso**: Ver `GUIA_USO.md`\n- **Cambios**: Ver `CHANGELOG.md`\n\n---\n\n**¿Necesitas ayuda?**\nVerifica que:\n1.
